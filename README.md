# NetMap 3D — Интерактивный 3D-симулятор топологии компьютерных сетей

> **Премиальное веб-приложение для проектирования, визуализации и симуляции компьютерных сетей в интерактивном трехмерном кибернетическом пространстве.**

## 🌟 Ключевые возможности

### 1. Футуристический дизайн в стиле Cyber-Tech Glassmorphism
- **Темная неоновая палитра**: глубокий космический фон `#060913`, яркие акценты неонового циана (`#00f3ff`), электрического синего (`#3b82f6`), пурпурного (`#a855f7`) и сигнального зеленого (`#00ff9d`).
- **Стеклянные панели (Glassmorphism)**: плавающие полупрозрачные интерфейсы с размытием фона (`backdrop-filter: blur(16px)`).
- **Спецэффекты пост-процессинга**: кинематографическое неоновое свечение **UnrealBloomPass**, парящие частицы данных, анимированные импульсы по оптоволокну.
- **Процедурное аудио**: генерация звуков кликов, подключений, прыжков пакетов и алертов через Web Audio API без внешних аудиофайлов.

### 2. Интерактивная 3D-сцена (Three.js)
- **Полная свобода камеры**: плавное вращение орбиты, масштабирование (зум), панорамирование с демпфированием.
- **Быстрые ракурсы**: Сброс вида к центру сети (`R`), вид сверху 2D-план, изометрический ракурс, режим кинематографического вращения.
- **3D Drag-and-Drop**: прямое перетаскивание устройств мышью в плоскости пола X-Z. Все подключенные кабели мгновенно пересчитывают свои кривые в реальном времени!
- **Подсветка и билборд-лейблы**: парящие 3D-бейджы с именем узла, IP-адресом и статусом онлайн, всегда направленные к камере.

### 3. Библиотека сетевого оборудования (8 типов)
Каждое устройство имеет уникальную процедурную 3D-модель высокой детализации:
1. **Компьютер (ПК)** — широкоформатный монитор с активным терминалом, ножка, корпус Tower с RGB-подсветкой и клавиатура.
2. **Ноутбук** — раскрытый ультрабук с матрицей экрана, клавиатурным блоком и тачпадом.
3. **Маршрутизатор (Router)** — enterprise-шасси со скошенными гранями, 4 регулируемыми антеннами с неоновыми наконечниками и светодиодной индикацией.
4. **Коммутатор (Switch)** — стоечный 1U блок с 24 портами RJ-45 и мерцающими индикаторами активности портов.
5. **Сервер (Server)** — массивный 4U шкаф-сервер с выдвижными блейд-модулями, корзинами дисков и направляющими.
6. **Межсетевой экран (Firewall)** — бронированный шлюз безопасности с красным энергетическим ядром и голографическим куполом щита.
7. **Облако (Cloud)** — стилизованное кластерное облако из светящихся кибер-сфер с наклонным орбитальным кольцом передачи данных.
8. **База данных (Database)** — многоуровневый массив дисковых накопителей (SAN Platters) с вертикальными шинами данных.

### 4. Инструмент соединения кабелей (Connect Tool)
- Интерактивный режим соединения: клик по первому устройству (Source) $\to$ тянется динамическая 3D-направляющая к курсору $\to$ клик по целевому устройству (Target).
- Поддержка интерфейсов: **10 Гбит/с Оптика (Fiber)**, **1 Гбит/с Витая пара (Ethernet)**, **300 Мбит/с Wi-Fi**.
- Защита от дубликатов и запрет соединения устройства с самим собой.
- Моделирование разрыва кабеля с индикатором аварии.

### 5. Визуальный симулятор пакетов данных
- **Алгоритм Дейкстры**: расчет оптимального маршрута через активные узлы и неповрежденные соединения.
- **Физическая анимация**: неоновые пакеты перемещаются хоп-за-хопом по 3D-дугам кабелей с подсветкой пути.
- **Подтверждение доставки (ACK)**: при достижении адресата генерируется обратный пакет подтверждения.
- **Обработка аварий**: если кабель разорван или промежуточный узел выключен (офлайн), пакет взрывается искрами, фиксируется потеря пакета и выводится ошибка маршрутизации.
- **Телеметрия**: отображение времени RTT (мс), количества хопов, джиттера и процента потерь.

### 6. Управление проектами и сохранение
- Сохранение и загрузка проектов в **LocalStorage** браузера.
- Предустановленный проект: **«Кампусная сеть университета»** (ядро, распределение, доступ, серверы деканата, фаервол и Wi-Fi клиенты).
- Шаблон **«Дата-центр Enterprise»** (Spine-Leaf архитектура).
- Полный экспорт и импорт в `.json` файлы.
- Экспорт снимка 3D-топологии в ультра-четком **PNG** с кибер-маркировкой.

## 🚀 Быстрый запуск

### Способ 1: С помощью встроенного Python-сервера (Рекомендуется)
1. Убедитесь, что установлен Python 3 (доступен на большинстве систем).
2. В папке с проектом выполните команду:
   ```bash
   python serve.py
   ```
3. Сервер автоматически запустится на `http://localhost:8080` и откроет страницу в вашем браузере по умолчанию!

### Способ 2: Запуск через стандартный модуль Python
```bash
python -m http.server 8080
```
После чего откройте в браузере: [http://localhost:8080](http://localhost:8080)

### Способ 3: Запуск через Node.js (при наличии)
```bash
npx serve . -p 8080
```

## ⌨️ Горячие клавиши

| Клавиша | Действие |
|:-------:|:---------|
| `C`     | Включить / выключить режим интерактивного соединения |
| `R`     | Сбросить ракурс камеры к центру топологии |
| `P`     | Отправить случайный тестовый пинг |
| `Esc`   | Отменить текущее действие / закрыть панель |

## 🛠 Технологический стек
- **HTML5 & CSS3**: современные CSS Custom Properties, Flexbox, Grid, Glassmorphism Backdrop Filter.
- **JavaScript (ES Modules)**: модульная архитектура без жестких внешних зависимостей.
- **Three.js (r128)**: 3D рендеринг, освещение, OrbitControls, процедурная геометрия.
- **Post-Processing**: UnrealBloomPass для эффекта неонового кибер-свечения.
- **Web Audio API**: процедурный звуковой движок.
- **LocalStorage API**: надежное сохранение состояния между перезагрузками страницы.
